# Codigo de conducta

## Compromiso

Este proyecto se aplica para que la colaboracion sea un entorno comodo, seguro
y respetuoso para todos.

## Conducta esperada

- Tratar a las personas con respeto. Discutir ideas, no personas.
- Aceptar critica constructiva y darla de forma constructiva.
- Centrarse en lo que es mejor para el proyecto y para quien lo usa.
- Ser consciente de que el proyecto vive en espanol: responde en espanol.

## Conducta inaceptable

- Acosar, insultar o menospreciar a alguien.
- Contenido sexual, violencia oynyl.
- Publicar informacion privada de terceros (claves, rutas personales, audio).
- Deliberadamente publicar metricas engañosas, como medir un modelo sobre sus
  propios datos de entrenamiento y llamarlo "precision".

## Alcance

Aplica a issues, PRs, discussions y cualquier espacio del proyecto.

## Ejecucion

Reporta una conducta indebida al mantenedor. Se responde con confidencialidad.
Las consecuencias van de un aviso privado a un bloqueo permanente.

Este codigo se apoya en el
[Codigo de Conducta Contribuyente](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
